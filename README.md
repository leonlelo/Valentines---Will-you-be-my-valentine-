# Valentine Website 💕

En morsom "Will you be my Valentine?" nettside med rødt tema, hjerter og kyss.

## Funksjoner

- Romantisk design med rødt tema og flytende hjerter
- Interaktiv "Nei"-knapp som flytter seg når du prøver å klikke på den
- Lagring av svar på enheten (localStorage)
- Mobilvennlig design
- Feiring med flyvende hjerter når du sier ja!

## Teknologi

- HTML
- CSS
- JavaScript

## Bruk

Åpne `index.html` i nettleseren.
